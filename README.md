# Customer Churn Prediction using Machine Learning

## Project Overview

This project predicts customer churn using Machine Learning techniques. The objective is to identify customers who are likely to leave the service based on demographic, billing, and service-related information.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab

## Dataset

The dataset contains customer information such as:

- Gender
- Senior Citizen
- Tenure
- Monthly Charges
- Total Charges
- Contract Type
- Internet Service
- Payment Method
- Churn Status

## Project Workflow

1. Data Cleaning
2. Handling Missing Values
3. Feature Engineering
4. Encoding Categorical Features
5. Train-Test Split
6. Model Training using Random Forest Classifier
7. Model Evaluation
8. Feature Importance Analysis
9. Confusion Matrix
10. ROC Curve Analysis

## Results

### Model Performance

- Accuracy: 78%
- AUC Score: 0.86

### Important Features

- Tenure Months
- Total Charges
- Contract Type
- Monthly Charges
- Internet Service

## Visualizations

- Feature Importance Graph
- Confusion Matrix
- ROC Curve

## Conclusion

The Random Forest model successfully identified customers likely to churn. Feature importance analysis revealed that tenure, charges, and contract type significantly influence churn behavior.
